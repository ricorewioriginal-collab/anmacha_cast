# Quelle des GitHub-Wikis

Die Seiten in diesem Ordner sind die Quelle des [GitHub-Wikis](https://github.com/ricorewioriginal-collab/anmacha_cast/wiki). Der Workflow `.github/workflows/wiki-sync.yml` überträgt sie nach jedem Push auf `main` in das Wiki-Repository und ersetzt dessen Inhalt vollständig.

Änderungen am Wiki daher **hier per Pull Request** machen, nicht im Wiki-Editor auf GitHub (sie würden beim nächsten Abgleich überschrieben). Diese Datei selbst wird nicht ins Wiki übernommen.
