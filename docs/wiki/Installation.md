# AnMaCha Cast installieren

AnMaCha Cast läuft je nach Einsatz auf verschiedenen Plattformen. Die Studio-Oberfläche ist immer dieselbe.

| Variante | Geeignet für | Anleitung |
|---|---|---|
| Windows Installer | normaler Einsatz auf einem Windows-PC oder Studio-Rechner | [[Windows Installation]] |
| Windows Portable | ohne Installation, z. B. vom USB-Stick | [[Windows Installation]] |
| Linux-Server (DEB) | Dauerbetrieb auf Debian/Ubuntu mit systemd | [[Server und Docker]] |
| Docker | Server, NAS, Homelab, Raspberry Pi 4/5 (64 Bit) | [[Server und Docker]] |
| Android-App | Handy als Sender (Go Live) und Studio-Fernbedienung | [[Android und F-Droid]] |
| iPhone / iPad | Web-App ohne App Store | [[iPhone und Mobil-App]] |

Für einen normalen Windows-PC empfehlen wir den **Windows Installer**; er enthält Studio, Server, Audio-Engine (ffmpeg) und die Android-APK zum Verteilen im WLAN.

Alle Details, Optionen und Befehle stehen in der [Installationsanleitung im Repository](https://github.com/ricorewioriginal-collab/anmacha_cast/blob/main/docs/INSTALLATION.md).

## Danach: Updates

Unter **Updates** in der Seitenleiste zeigt AnMaCha Cast die installierte und die neueste Version an. Beim installierten Windows-Programm lässt sich das Update direkt einspielen; Portable, Server und Docker werden manuell aktualisiert. Vor jedem Update ein Backup anlegen.
